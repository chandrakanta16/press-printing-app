# Maa Santosi Computer

Modern MERN Stack website for Maa Santosi Computer featuring printing services, online digital solutions, admin dashboard, contact management, and responsive design.

---

## 🚀 Live Website

🌐 https://maasantosicomputer.vercel.app/

---

## 📌 Features

- Responsive Modern UI
- Mobile Friendly Navbar
- Animated Image Slider
- Professional About Section
- Contact Form with MongoDB
- Admin Login System
- Protected Dashboard Route
- Customer Message Management
- Delete Multiple Messages
- React Router Navigation
- Fully Responsive Design
- MERN Stack Architecture
- Online Deployment (Vercel + Render)
- Book Publication Showcase
- Printing & Digital Service Management

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- CSS3
- Axios
- Vite

### Backend
- Node.js

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Rabindra760/maa-santosi-computer.git
```

---

## Frontend Setup

```bash
cd client

npm install

npm run dev
```

---

## Backend Setup

```bash
cd server

npm install

npm run dev
```

---

## 🔐 Environment Variables

### Frontend `.env`

```env
VITE_API_URL=https://your-backend-url.onrender.com
```

---

### Backend `.env`

```env
PORT=5000

MONGO_URL=your_mongodb_connection_string
```
